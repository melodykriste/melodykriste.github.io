# 铁路线路标段建设监控大屏

## 项目简介

这是一个专为铁路建设部门设计的监控大屏系统，支持通过配置经纬度在地图中生成铁路路线，实时展示铁路线路标段建设的总体效果情况。

## 功能特点

### 🗺️ 地图展示
- 基于 Leaflet 地图库，支持深色主题
- 实时显示铁路路线和建设进度
- 支持多种路线类型的颜色区分
- 交互式地图操作（缩放、拖拽、点击查看详情）

### 📍 路线配置
- **坐标输入**：支持精确的经纬度坐标输入
- **路线类型**：
  - 主干线（蓝色 #00d4ff）
  - 支线（绿色 #00ff88）
  - 城际线（橙色 #ff9500）
  - 货运线（红色 #ff453a）
- **建设状态**：
  - 规划中
  - 建设中（带脉冲动画效果）
  - 已完成
  - 暂停

### 📊 实时监控
- **统计面板**：总路线数、在建路线、已完成路线、总体进度
- **进度展示**：各项目建设进度条
- **系统状态**：实时系统运行状态提醒

### 🎛️ 管理功能
- 添加新路线
- 编辑现有路线
- 删除路线
- 路线列表管理

## 使用方法

### 1. 打开页面
直接在浏览器中打开 `railway-monitor.html` 文件即可。

### 2. 添加路线
1. 在左侧"路线配置"面板中填写：
   - 路线名称
   - 起点坐标（纬度、经度）
   - 终点坐标（纬度、经度）
   - 路线类型
   - 建设状态
2. 点击"添加路线"按钮
3. 路线将立即显示在地图上

### 3. 管理路线
- **查看详情**：点击地图上的路线查看详细信息
- **编辑路线**：在路线列表中点击"编辑"按钮
- **删除路线**：在路线列表中点击"删除"按钮

### 4. 快捷键
- `Ctrl + Enter`：快速添加路线

## 坐标获取方法

### 方法一：在线地图工具
1. 打开高德地图或百度地图
2. 右键点击目标位置
3. 选择"这里是哪里"或类似选项
4. 复制显示的经纬度坐标

### 方法二：GPS设备
直接使用GPS设备或手机GPS功能获取当前位置坐标。

### 方法三：地理信息系统
使用专业的GIS软件获取精确坐标。

## 部署说明

### 本地部署
1. 下载 `railway-monitor.html` 文件
2. 双击打开或通过Web服务器访问

### 服务器部署
1. 将文件上传到Web服务器
2. 确保服务器支持HTTPS（地图API要求）
3. 配置适当的MIME类型

### 大屏部署
1. 设置浏览器全屏模式（F11）
2. 禁用屏幕保护程序
3. 设置自动刷新（可选）

## 常见问题

### Q: 地图无法加载？
A: 检查网络连接，确保可以访问地图瓦片服务。

### Q: 坐标输入后路线不显示？
A: 检查坐标格式是否正确，纬度范围 -90 到 90，经度范围 -180 到 180。

### Q: 如何保存配置？
A: 当前版本使用浏览器本地存储，数据会自动保存。

### Q: 可以导入/导出数据吗？
A: 当前版本不支持，可以通过二次开发添加此功能。
