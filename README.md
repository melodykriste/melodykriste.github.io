# 预警参数设置管理系统

## 项目概述

本项目实现了一个完整的预警参数设置管理系统，用于优化现有预警参数展示方式，并新增11种预警参数规则。系统支持业主单位对各种预警类型进行配置管理，并集成到支付流程中实现实时预警监控。

## 功能特性

### 🛡️ 11种预警类型

1. **关键字预警** - 检测收款关键字及备注或摘要关键字
2. **黑名单预警** - 检测收款方是否在黑名单中
3. **重复性预警（金额）** - 月度内收付款方金额相同预警
4. **重复性预警（频次）** - 同一收款人频次超限预警
5. **司法冻结预警** - 监管账户司法冻结或扣划预警
6. **资金挪用预警（工资）** - 农民工工资超平均数预警
7. **关联方预警** - 施工单位向关联企业支付预警
8. **代发支付混用预警** - 代发资金模块对公账户付款预警
9. **考勤未发工资预警** - 已有考勤但未发工资预警
10. **实发应发不一致预警** - 实发与工资表应发金额不一致预警
11. **超期未发工资预警** - 超期未发工资预警

### ⚙️ 核心功能

- **预警参数配置** - 支持开启/关闭预警，设置预警级别和处置方式
- **三种处置方式** - 仅查看、直接拒绝、业主审核
- **黑名单管理** - 支持Excel文件上传和模板下载
- **预警查看** - 按风险等级查看预警信息
- **预警统计** - 预警数据统计和图表展示
- **支付流程集成** - 实时预警检查和处理

## 预警规则详解

### 1. 关键字预警
- **触发条件**：备注/摘要或收款单位名称包含敏感关键字
- **默认关键字**：现金、借款、个人
- **可配置项**：关键字列表、预警级别、处置方式

### 2. 黑名单预警
- **触发条件**：收款方名称或账号在黑名单中
- **数据来源**：Excel文件上传
- **可配置项**：预警级别、处置方式

### 3. 重复性预警
- **金额预警**：月度内相同付款账户、收款账户、金额
- **频次预警**：指定天数内向同一收款人付款超过阈值
- **可配置项**：时间范围、次数阈值、预警级别、处置方式

### 4. 司法冻结预警
- **触发条件**：监管账户发生司法冻结或扣划
- **默认级别**：高风险
- **可配置项**：处置方式

### 5. 资金挪用预警
- **工资预警**：农民工工资超过平均数倍数
- **代发混用**：代发资金模块进行对公账户付款
- **可配置项**：倍数阈值、预警级别、处置方式

### 6. 农民工相关预警
- **考勤未发工资**：有考勤记录但未发工资
- **实发应发不一致**：实发金额与工资表不符
- **超期未发工资**：超过进场时间未发工资
- **可配置项**：时间阈值、预警级别、处置方式

## 处置方式说明

### 仅查看
- 显示预警信息但不阻止支付
- 记录预警历史供后续查看
- 适用于提醒性预警

### 直接拒绝
- 阻止支付申请提交
- 显示拒绝原因
- 适用于高风险预警

### 业主审核
- 将支付申请提交给业主审核
- 暂停自动处理流程
- 适用于需要人工判断的预警

## 扩展开发

### 添加新的预警类型

1. **在WarningManagementSystem类中添加检查方法**：
```javascript
checkNewWarningType(paymentData) {
    // 实现预警逻辑
    if (condition) {
        return {
            type: 'newWarningType',
            level: 'medium',
            action: 'view',
            message: '预警消息',
            details: { /* 详细信息 */ },
            timestamp: new Date().toISOString()
        };
    }
    return null;
}
```

2. **在checkWarnings方法中调用**：
```javascript
if (this.warningConfigs.newWarningType.enabled) {
    const newWarning = this.checkNewWarningType(paymentData);
    if (newWarning) warnings.push(newWarning);
}
```
