## 交互流程

### 1. 预警配置流程
```
开始 → 选择预警类型 → 开启预警开关 → 配置预警参数 → 保存配置 → 结束
                                    ↓
                               配置预警级别
                                    ↓
                               配置处置方式
                                    ↓
                               配置特定参数
```

### 2. 预警触发流程
```
业务操作 → 预警检测 → 触发预警 → 弹窗提示 → 用户处理 → 记录日志
                         ↓
                    根据处置方式:
                    - 仅查看: 显示提示
                    - 直接拒绝: 阻止操作
                    - 业主审核: 提交审核
```

### 3. 预警处理流程
```
预警列表 → 选择预警 → 查看详情 → 处理决策 → 执行处理 → 更新状态
                                    ↓
                               处理选项:
                               - 通过
                               - 拒绝
                               - 需要更多信息
```

## 数据模型

### 预警配置数据结构
```javascript
{
  id: "warning_001",
  name: "关键字预警",
  type: "keyword",
  enabled: true,
  level: "medium", // medium | high
  processType: "view_only", // view_only | direct_reject | owner_review
  config: {
    keywordType: "remark", // remark | payee
    keywords: ["转账", "借款", "个人"]
  },
  createdAt: "2024-01-01T00:00:00Z",
  updatedAt: "2024-01-20T10:30:00Z"
}
```
