1. **创建新项目**

   ```

   ├── ⚙️ 预警参数设置 (WarningSettings)
   ├── 📊 预警历史记录 (WarningHistory)
   ```

### 第五步：添加交互逻辑（20分钟）

#### 1. 预警卡片开关交互
```javascript
// 伪代码 - Axure中的条件逻辑
OnClick 开关按钮:
  IF [[Item.enabled]] == "true"
    Set [[Item.enabled]] = "false"
    Set 状态文本 = "● 已禁用"
    Set 状态颜色 = 灰色
    Disable 配置表单
  ELSE
    Set [[Item.enabled]] = "true" 
    Set 状态文本 = "● 已启用"
    Set 状态颜色 = 绿色
    Enable 配置表单
```

#### 2. 修改配置按钮交互
```javascript
OnClick 修改配置按钮:
  IF [[currentUser]] == "owner"
    Show 配置弹窗
    Load 当前配置数据
  ELSE
    Show 权限提示消息
```

#### 3. 预警弹窗显示逻辑
```javascript
// 模拟预警触发
OnPageLoad:
  Wait 2000ms
  Set selectedWarning = "blacklist"
  Show 预警弹窗
  Set 弹窗内容 = 黑名单预警数据
```

#### 4. 表格筛选功能
```javascript
OnSelectionChange 筛选下拉框:
  Filter 中继器数据

  Refresh 表格显示
```

## 🔧 常见问题解决

**Q: 开关组件如何制作？**
A: 使用矩形背景+圆形滑块，通过动态面板的状态切换实现

**Q: 如何实现表格的排序功能？**
A: 在中继器的交互中添加"Sort"动作，按指定字段排序

**Q: 弹窗如何居中显示？**
A: 设置动态面板位置为"Center"，或使用固定坐标计算

**Q: 如何实现数据的动态更新？**
A: 使用全局变量存储数据，通过"Set Text"动作更新显示
