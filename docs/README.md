## 🎯 核心功能

### 预警系统包含11种预警类型：

1. **🔍 关键字预警** - 检测敏感关键字
2. **🚫 黑名单预警** - 收款方黑名单检测
3. **🔄 重复付款预警** - 相同收款方和金额检测
4. **⚡ 频繁付款预警** - 同一收款方频繁付款
5. **⚖️ 司法冻结预警** - 账户司法冻结检测
6. **💰 工资挪用预警** - 工资超平均水平检测
7. **🔗 关联方预警** - 关联企业支付检测
8. **🔀 代发混用预警** - 代发资金混用检测
9. **📅 考勤未发预警** - 有考勤无工资检测
10. **📊 工资不一致预警** - 实发应发不一致
11. **⏰ 工资超期预警** - 超期未发工资检测

### 主要页面：
- **预警参数设置页面** - 配置各类预警规则
- **预警历史记录页面** - 查看和处理预警记录
- **预警弹窗组件** - 实时预警提示

## 🎭 交互逻辑

### 权限控制
- **业主用户**：可配置所有预警参数
- **施工单位**：只能查看预警信息
- **复核员**：可处理预警记录

### 预警处置方式
- **仅查看**：显示预警提示，不阻止操作
- **直接拒绝**：阻止操作提交
- **业主审核**：提交至业主审核

### 状态管理
- **待处理**：新触发的预警
- **已处理**：已完成处理的预警
- **已忽略**：用户选择忽略的预警

## 🔍 常见问题

**Q: 如何在Axure中实现开关组件？**
A: 使用矩形背景+圆形滑块，通过动态面板的状态切换实现滑动效果。

**Q: 中继器数据如何动态更新？**
A: 使用全局变量存储数据状态，通过"Add Row"、"Update Row"、"Delete Row"等动作操作中继器数据。

**Q: 如何实现权限控制？**
A: 设置全局变量 `currentUser`，在页面加载时根据用户角色显示/隐藏相应功能。

**Q: 弹窗如何实现居中显示？**
A: 将弹窗放在动态面板中，设置面板位置为"Center"，或使用固定坐标计算屏幕中心位置。

**Q: 如何实现表格的筛选功能？**
A: 在筛选控件的交互中添加"Filter"动作，设置筛选条件，同时更新统计数据。
